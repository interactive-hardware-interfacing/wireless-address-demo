About this demo

What it shows

Every device on a network has an address, and messages carry the address of who they’re for. Here, three identical boards each have an address; you pick a recipient and send a message, and only the addressed board lights up. Switch to All and it’s a broadcast — everyone hears it at once. It’s the idea behind the “to:” line on an email and the MAC address on everything on Wi-Fi.

Try this during the tour: send to Node 2 — only Node 2 blinks. Send to All — all three blink. Ask the group why Node 1 ignored the message meant for Node 2 (it checked the address and it wasn’t his).

How it works

You pick a recipient; the page sends SEND <1|2|3|ALL> <text> to the bridge → the bridge radios a packet carrying a target address → every node hears it, but only the one whose id matches (or everyone, on broadcast) reacts. For a single node, the bridge can use real ESP-NOW unicast and report the radio-level ACK; a broadcast has no ACK by design. By default nodes filter on a 1-byte id so it works without a MAC census; flip USE_MAC on to use real per-node MAC unicast (each node prints its MAC on boot). See PROTOCOL.md.

The “sniff” aside: notice every node physically receives every packet — it just chooses to ignore ones not addressed to it. That’s why addressing is politeness, not privacy, and why encryption exists.

Known quirks:

  • Broadcast (All) gets no ACK — that’s correct, not a failure. Only unicast is acknowledged.
  • If a node is off or out of range, a unicast to it shows “no ACK.” Good teaching moment.
  • All boards pin channel 6. Loose antenna → nothing heard; check the u.FL.
  • Set MY_ID to 1/2/3 before flashing each node — easy to forget and flash two the same.
  • Flashing stuck? Hold BOOT, tap RESET, release BOOT.

Put the firmware on the boards

Four boards: one bridge, three nodes. All run CircuitPython.

  1. Install CircuitPython on each XIAO ESP32-C3 if needed (board page).
  2. Bridge: copy firmware/bridge/code.py. Plug this one into the laptop.
  3. Nodes: copy firmware/node/code.py to each, and set MY_ID to 1, 2, 3 — one per board. Wire an LED on D10 (or rely on the onboard LED).
  4. (Optional) real MAC unicast: each node prints its MAC on boot; copy those into the bridge’s NODE_MACS and set USE_MAC = True.
  5. Connect. Click Connect bridge, pick the USB JTAG/serial port, then send away.
